{%- comment -%} Search bar for the post list. Rendered on the home page (_layouts/home.html), above the cards it filters. The whole block ships `hidden` and assets/search.js unhides it, so a visitor without JavaScript never sees an input that cannot do anything — they still get the paginated list and the tag archives. The index URL rides on `data-search` because search.js is a plain static asset (no Liquid), and it is the only thing in there that needs to know the baseurl. {%- endcomment -%}
